End-to-end encrypted community client

Private communication, without the noise.

KrynetAI.free is an unofficial community project providing a privacy-focused client experience with end-to-end encrypted messaging.

Important: This project is not Krynet.ai and is not affiliated with or operated by Krynet.ai.
🔐

End-to-End Encryption

Messages are encrypted on the client before they are sent. The relay should only handle encrypted message packets.

🗝️

Client-Side Keys

Encryption identities are generated locally using the browser Web Crypto API and can be persisted locally.

🛡️

Authenticated Encryption

Messages use AES-256-GCM with unique nonces and authenticated message data.

🌐

Open Community

The project is built around an open community client rather than pretending to be the official Krynet service.
